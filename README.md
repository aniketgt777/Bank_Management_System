# 🏦 Bank Management System using Python

## 📌 Project Overview

This is a console-based Bank Management System developed using Python. The project demonstrates the use of object-oriented programming (OOP), JSON file handling, and basic banking operations. It allows users to create accounts, perform transactions, and securely store account data.

---

## 🎯 Features

- Create a new bank account
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- View transaction history
- Save account data to a JSON file
- Load existing account data automatically
